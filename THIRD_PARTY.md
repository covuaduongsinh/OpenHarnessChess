# Third-party licenses (OHCC compliance ledger)

This project ships under the **MIT License**. Domain work (OHCC) must stay commercializable.

## Policy

| Allowed | Forbidden |
|---------|-----------|
| MIT, Apache-2.0, BSD-2/3, ISC, Unlicense | GPL, AGPL, LGPL (avoid for simplicity) |
| Arasan chess engine (MIT) | Stockfish (GPL) |
| Custom heuristics | Maia Chess (GPL) |
| Own FEN/PGN code | python-chess (GPL-3) |

Before adding any dependency: record it here and run a license check.
